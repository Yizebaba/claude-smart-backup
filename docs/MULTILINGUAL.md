# AI Chat Backup - 多语言支持

## 中文 (Chinese)

### 简介

🎯 **通用 AI 聊天备份系统** - 智能触发、自动恢复、跨平台

支持 10+ AI 编程助手，包括 Claude Code、Cursor、Windsurf 等。

### 功能特性

- ⏰ **时间触发** - 每 N 小时自动备份
- 💬 **消息触发** - 新增 N 条消息时备份
- ✅ **任务触发** - 完成 N 个任务时备份
- 🔄 **模型切换** - 自动检测并恢复

### 快速开始

```bash
# 克隆仓库
git clone https://github.com/Yizebaba/claude-smart-backup.git
cd claude-smart-backup

# 安装
./install.sh

# 查看状态
python3 monitor.py --status
```
